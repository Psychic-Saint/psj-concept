# Port St Johns LM website redesign concept

Design concept prepared by **Warm & Easy Blueprints** (Eddie Bila) for tender **PSJLM-CORP-2026/27-07**: redesigning, hosting, support and maintenance of the Port St Johns Local Municipality website.

This is a proposal prototype, **not** the official municipal website. The official site is https://psjmunicipality.gov.za/.

Pages: `index.html` (homepage), `vacancies.html` (eRecruitment), `tenders.html` (procurement board). Crest, wordmark and photographs belong to Port St Johns Local Municipality. Content in [brackets] and the vacancy listings are sample content.
