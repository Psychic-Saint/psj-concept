# Port St Johns LM website redesign concept

Design concept prepared by **Warm & Easy Blueprints** (Eddie Bila) for tender **PSJLM-CORP-2026/27-07**: redesigning, hosting, support and maintenance of the Port St Johns Local Municipality website.

This is a proposal prototype, **not** the official municipal website. The official site is https://psjmunicipality.gov.za/.

## Pages
- `index.html` homepage: cinematic photo slideshow, animated river waves from the municipal crest, live notices ticker, filterable notice board, live tender countdown, live local weather, instant search, mega menus
- `vacancies.html` eRecruitment: live job filters, step-by-step online application, SMS application tracking
- `tenders.html` procurement: tabbed tender adverts, RFQs, intent to award, awards and SCM notices, bidder checklist, tender box map

## Built in
Mobile-first layout, Lite mode for low-bandwidth users (remembered per device), respects reduced-motion settings, keyboard accessible, POPIA/PAIA links, no build step (plain HTML, CSS and JavaScript).

Crest, wordmark and photographs belong to Port St Johns Local Municipality. Content in [brackets] and the vacancy listings are sample content.
